Sobre o Projeto

A Adega Caminho Novo é um projeto de e-commerce criado com o propósito de valorizar os vinhos brasileiros e aproximar os consumidores da diversidade da produção vitivinícola nacional. Inspirado no antigo Caminho Novo, rota histórica que conectava Minas Gerais ao Rio de Janeiro, o projeto utiliza essa referência para construir uma identidade que une história, cultura e valorização dos produtos brasileiros.

Durante o desenvolvimento, trabalhei na construção do projeto e na implementação de funcionalidades voltadas à experiência dos usuários, incluindo os recursos de cadastro e autenticação. A aplicação utiliza Java e Spring Boot, com integração ao Spring Data JPA para persistência de dados e Spring Security para os recursos de segurança e controle de acesso.

O projeto representa minha experiência na criação de uma solução digital com propósito comercial, combinando desenvolvimento de software, organização de funcionalidades e construção de uma identidade própria para o negócio.

Destaques de Implementação

  • Layout Responsivo & Visual Premium: Design adaptado com paleta de tons quentes e escuros que realçam o catálogo de produtos.
  • Navegação Interativa: Filtros dinâmicos e carrinho de compras simulado no front-end para validação de usabilidade.
  • Organização Semântica: Estruturação limpa em HTML5 e estilização modularizada em CSS3.
